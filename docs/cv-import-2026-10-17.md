## Source and publishing controls

Official PDFs came from https://www.topps.com/pages/checklists. Every reviewed product input records its exact PDF URL, SHA-256 hash, page count, and withheld-source count. The import catalog separately records the expected total, per-subset counts, and input file checksum. Multi-line card numbers and subjects are aligned by their page coordinates; repeated subject lines on dual/triple cards become a single card identity within that subset.

`data/cv-reviewed-imports` contains the reviewed input snapshots. The build restores them only where the product is absent/empty. A later populated export wins and is mirrored into the direct product endpoint and search data. Five All Kings rows are appended only if missing; conflicting existing records are preserved and reported. Re-running the import makes zero changes.

Published data includes sport manifests, the CV catalog, complete card/player search rows, and direct per-product JSON. The direct endpoint avoids the failed per-product request and fallback lookup for these products. The checklist manifest version is advanced while the PRV source version remains unchanged. The refresh workflow includes the import inputs and CV files so a later export cannot silently erase the reviewed fallback records.

No Google Sheets or Sentinel settings were changed. These are versioned GitHub data additions with rebuild protection. Source PDFs and raw extraction records remain available in the local review directory.

## Validation files

Local review folder: `outputs/cv-import-2026-10-17`.

- `published-card-review.csv`: every added card, its subset, source page, source heading, and official PDF URL.
- `withheld-records.json`: the 301 source records held for review.
- `manifest.json` and `layout-review.json`: identity, source URLs, page layouts, and headings.
- `sources`: original PDFs and extracted text.
- `parsed`: page-level source evidence and normalized proposed card rows.

Parallel variants and their serials still require odds-sheet/product-specific review. A checklist card import does not establish complete parallel coverage. The historical page-wide unmatched-title backlog and the 32 Football scope-name comparisons are separate follow-up audit work.
